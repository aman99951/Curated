# Curated Talent Marketplace

A trusted, founder-led marketplace connecting businesses with independent specialists. Currently operating as a private, manually curated pilot.

## Getting started

Open `index.html` in a browser — no build step or dependencies required.

## Features

- Curated freelancer / boutique agency categories
- Project enquiry and talent sign-up forms
- Manual, reviewed matching (no automated verification live yet)
- Responsive layout with mobile navigation
